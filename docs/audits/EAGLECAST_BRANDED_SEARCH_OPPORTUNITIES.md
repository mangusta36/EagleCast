## Search opportunity priorities

1. **P0 — Measure first:** obtain GSC query + page data for the listed clusters, US, desktop/mobile, 3- and 16-month ranges. Compare homepage exact-query data with support-page exact-query data.
2. **P1 — Maintain differentiated intent:** retain the homepage as broad service context while plans, trial, login, portal, status and device documents address their own tasks.
3. **P1 — License-aware trust:** after approved wording is supplied, evaluate whether a short, factual disclosure improves user clarity. Do not publish it beforehand.
4. **P2 — Improve useful support discovery:** use GSC queries to identify factual gaps in existing setup and troubleshooting resources before proposing new pages.

## Not recommended

- Creating pages designed to intercept users clearly navigating to the brand-owner domain.
- Calling this site official, authorized, a partner, or a reseller without approved language.
- Creating review, legality, or app-download pages without independently supportable facts.
- Treating shared brand mentions as cannibalization without GSC page data.
