# EagleCast brand license scope verification

**Evidence standard:** the operator states permission or a license to use the EagleCast TV brand. That is an **OWNER-STATED** fact, not independent proof of scope. `eaglecast.tv` is identified as the brand owner’s domain and is not owned by this operator.

| Permission / fact             | Classification | Evidence available                                       | Exact owner confirmation required                                                                | Affected public surfaces                    |
| ----------------------------- | -------------- | -------------------------------------------------------- | ------------------------------------------------------------------------------------------------ | ------------------------------------------- |
| Use of “EagleCast TV” name    | OWNER-STATED   | Phase 4 owner statement                                  | License document or approved scope, territories, channels, and expiry/review date                | Sitewide name, title, H1, metadata          |
| Logo / visual assets          | UNVERIFIED     | None in repository                                       | Which exact files/logos are licensed, permitted modifications, attribution rules                 | `app/icon.svg`, visual assets, OG assets    |
| Relationship description      | BLOCKED        | No approved wording                                      | Approved public wording: licensee, reseller, partner, or other; disclosure placement             | About, footer, contact, schema, metadata    |
| Reseller/partner disclosure   | UNVERIFIED     | A reseller page exists but no license evidence           | Whether status may be publicly stated and its approved wording                                   | `app/reseller/page.tsx`, About, footer      |
| “Official” designation        | BLOCKED        | Operator does not own brand-owner domain                 | Explicit authorization to call this an official primary/authorized website; otherwise prohibited | All public copy and schema                  |
| `@eaglecast.tv` support email | UNVERIFIED     | Source uses addresses but ownership is not proved        | Written authorization for each address and support responsibility                                | Contact data, footer, support pages, schema |
| Social accounts               | BLOCKED        | No approved profiles supplied                            | Exact owned/authorized account URLs and `sameAs` permission                                      | Schema, header/footer                       |
| App ownership/download rights | BLOCKED        | No approved app evidence                                 | Publisher, official download URL, platforms, support and branding rights                         | Any future app page/FAQ/schema              |
| Customer reviews/testimonials | BLOCKED        | No permissioned review evidence                          | Which testimonials/reviews belong to this operator and publication consent                       | Future testimonials, Review schema          |
| Commercial/geographic rights  | UNVERIFIED     | Existing site makes service claims; scope not documented | Approved markets, customer types, promotions and restrictions                                    | Homepage, pricing, services, trial          |
| License expiry/review date    | UNVERIFIED     | None                                                     | Expiry, renewal/review owner, revocation/use rules                                               | Editorial governance                        |

## Owner questions

1. Provide the license or a written authorization that identifies the permitted brand name, territory, website domain, and effective/expiry dates.
2. Provide approved public relationship wording, if any. May the site use “authorized,” “licensed,” “reseller,” or “partner”? May it use “official”?
3. List approved visual assets, email addresses, social profiles, applications, download URLs, reviews, testimonials, and commercial claims.
4. State whether `eaglecastv.online` may publish any association with `eaglecast.tv`; if yes, provide exact approved language and placement.
5. Identify the person responsible for periodic license and factual-content review.

Until these answers exist, do not add relationship claims, `sameAs`, review/rating markup, app-download content, or brand-owner identity signals.
